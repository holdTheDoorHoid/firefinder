Cerro Gordo is a lookout site on the Fort Apache Indian Reservation in Apache County, Arizona.[^1][^2] The Forest Fire Lookout Association lists it as a tower and marks it gone.[^2]

The Peakbagging table of Arizona lookout sites has an entry for Cerro Gordo Mountain at the same coordinates as the association's listing, and it codes that entry B.[^3][^2] In the table's key, code B means the structure is in poor repair but still standing.[^3] The table was revised on October 2, 2024.[^3]

The two listings therefore disagree about whether anything is left, and the sources I read do not settle it.[^2][^3]

Today, no source I read describes the site on the ground. The table's code points to a structure that still stands, which is the opposite of the association's entry.[^3][^2] The site lies on reservation land.[^1] None of the sources I read says whether the public may visit, so a visitor should ask for permission first and should not climb any structure that remains.
