A Georgia lookout tower index lists a tower named Fort Benning, in Chattahoochee County, with an elevation of 493, read as feet (about 150 m).[^1] A separate list of Georgia lookouts from the Forest Lookouts website includes the same name and county.[^5]

Fort Benning is an Army installation in Georgia.[^2] Since 1918, most of the county's land has been inside the Fort Benning reservation.[^3]

The index also lists two more Fort Benning points, labelled S and E, whose source is listed as 1950 Army topographic maps.[^1] It is not clear from the index whether these are separate towers or the same one.

The National Geodetic Survey lists a survey station called Fort Benning Fire Tower, numbered CM1885, at nearly the same spot.[^4][^1] One entry for that station carries a code for a surface mark reported destroyed. The other carries a code for no geodetic control.[^4]

No source describes the tower itself today, so it is not known whether any part of it still stands. The name belongs to an Army post, so the public should not assume it can visit.[^2] No source describes access to the tower.
