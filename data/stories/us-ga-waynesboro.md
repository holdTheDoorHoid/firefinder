Tom Dunigan's list of Georgia lookout towers places a tower at this point in Burke County. The list's entry carries the number gfc-101, which comes from an older Georgia Forestry Commission list that described the locations of 203 towers.[^1] The list numbers this entry GA255, and the page says names for towers from number 73 on are the author's own creation, so "waynesboro" is a label rather than a documented title.[^1]

A "Looking Back" column in The True Citizen recalls news from April 11, 1940. T.W. Mobley gave ten acres for the county's first fire lookout tower, which the Civilian Conservation Corps was to build. The column calls that tower the easternmost of five planned for the county.[^2] The column gives no location, so it is not certain that it describes this tower.[^2]

We found no source on how this tower was staffed, whether it saw any fires, or what became of it. No source describes the site today, so we cannot say whether a tower still stands there or whether the land is open to visitors.
