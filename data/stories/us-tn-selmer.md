The register calls it the Selmer Lookout Tower, while Tennessee Landforms and a 2014 count use the name Bethel Springs. All three sources place it in McNairy County.[^1][^2][^3] We treat them as one tower, although the match rests on county and name.

The register describes an 80-foot Aermotor LS-40 at 576 feet elevation, administered by the Tennessee Division of Forestry.[^1] According to a National Register study, the LS-40 later became the favored tower type of both the Division and the Forest Service.[^3] We could not find a build date for this tower in the sources we read.

Tennessee Landforms lists it with state forest number 8-18, a number taken from a 1976 list of Division towers, and marks it standing.[^2]

The register says the state is using the site now and records a site visit dated March 6, 2022.[^1] Because the site is in state use, this story does not suggest visiting or climbing the tower.[^1]
