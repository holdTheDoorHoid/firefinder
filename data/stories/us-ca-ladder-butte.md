Ladder Butte is a peak in the Lassen National Forest, with an elevation of 5,746 feet.[^1] In November 1932 the forest's supervisor wrote to the Red River Lumber Company asking permission to use its poles for a telephone line, so that a planned lookout could link up with the forest's main phone system.[^2] The same letter said a lookout house would go up on the peak before the next fire season, and that it would give a wide view from Hat Creek to Black's Mountain.[^2]

A later site note puts a wooden building on the peak in 1932. It says the building was still standing in 1948, when surveyors inspected it and found it in poor condition.[^1] The letter points to the following spring, so the two sources disagree about the year.[^2]

The state list classifies the structure as a two-story cab.[^3] A Forest Lookouts page marks the lookout as "Removed," and the site note says only foundation bolts are left.[^2][^1] A 2012 photo on the same note looks west toward Burney Mountain.[^1]

Today, a hiking app lists a trail named Ladder Butte Lookout through the national forest.[^4] Beyond that listing, no source describes the site today.
