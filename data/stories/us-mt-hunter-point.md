Hunter Point is a lookout site in Missoula County, about 28 miles east of Missoula, at an elevation of 4,019 feet.[^1]

The lookout was a 30-foot L-4 tower dated to 1944.[^1] The listing names Montana DNRC as the agency connected to the site.[^1] A Montana lookout list spells the name Hunters Point.[^4]

The Forest Fire Lookout Association and firelookout.com both list the tower as gone.[^2][^1]

A travel guide to Clearwater State Forest, which it places in Missoula County, says a hike leads up to the Hunter Point Lookout Tower.[^3] That claim conflicts with the two listings, so the sources disagree on whether the tower still stands.[^1][^2][^3]

The state forest is open year-round, and the guide says any recreational activity on state trust land, hiking included, needs a Recreational Use License.[^3] Beyond that guide, no source describes the site today. Anyone visiting should not assume that any tower there can be climbed, and should check with the land manager before going.
